Add an Agent Skill

Choose a domain server, add its configuration to your MCP client, and authenticate with your YouCam API key.

Install the complete YouCam skill collection, set your API key, and invoke a workflow from your agent. MCP is not required.

  1. Add the connector

    Install the YouCam skills

    Paste the selected MCP configuration into your client.

    Run npx skills add youcam to install the complete skill collection.

  2. Add your API key

    Get a Bearer key from the API Console, then add it to your MCP configuration or set YOUCAM_API_KEY for Agent Skills.

  3. Call it from chat

    Ask in plain English; your agent selects the right tool and returns structured results.

    Invoke a skill; it calls the required APIs and returns a formatted report with result media.

MCP server
{
  "mcpServers": {
    "youcam-beauty": {
      "command": "npx",
      "args": ["-y", "mcp-remote",
        "https://mcp-api-01.makeupar.com/mcp/beauty",
        "--header", "Authorization:${AUTH}"],
      "env": { "AUTH": "Bearer YOUR_API_KEY" }
    }
  }
}
{
  "mcpServers": {
    "youcam-beauty": {
      "url": "https://mcp-api-01.makeupar.com/mcp/beauty",
      "type": "http",
      "headers": { "Authorization": "Bearer YOUR_API_KEY" }
    }
  }
}
